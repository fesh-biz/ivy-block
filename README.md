# Ivy Block

Блокова головоломка для Android: перетягуй фігури на поле 8×8, заповнюй рядки та стовпці, збирай комбо.
А ще є звичайний тетріс.

## Режими

- **Класика.** Безкінечна гра на рекорд. Прогрес зберігається після кожного ходу, тож можна закрити застосунок і продовжити пізніше.
- **Тетріс.** Класичний тетріс на полі 10×20: 7 фігур, «мішок» із 7 фігур, повороти SRS із відскоком
  від стін, запас (hold), три наступні фігури, тінь падіння. Кожні 10 ліній рівень зростає й фігури падають
  швидше. Очки за правилами Tetris Guideline: 100/300/500/800 × рівень, T-спіни, B2B ×1.5, комбо.
  Керування: торкнись поля, щоб повернути; веди пальцем, щоб рухати; веди вниз, щоб прискорити; різкий змах
  вниз скидає фігуру, змах угору відкладає її в запас. Кнопки внизу дублюють усе. Гра зберігається, тож її
  можна продовжити пізніше. З клавіатури: ← → ↓, ↑/X і Z повороти, пробіл скинути, C запас, Esc пауза.
- **Челенджі.** 50 рівнів із метою та обмеженою кількістю фігур:
  - 🍃 **листочки**: збери листочки плюща, вони зникають разом зі своїм рядком або стовпцем;
  - ➕ **лінії**: очисти N ліній;
  - 💎 **очки**: набери N очок.

  Від залишку фігур залежить, скільки зірок (1–3) отримаєш за рівень. Наступний рівень відкривається після проходження попереднього.

## Завантажити APK

Кожен пуш у `main` збирає APK у GitHub Actions і публікує його в релізі
[**latest**](../../releases/tag/latest). Файл `IvyBlock.apk` встановлюється прямо на телефон
(Android 8.0+, потрібно дозволити встановлення з невідомих джерел).

## Як влаштовано

```
app/src/main/assets/www/   гра (HTML5 Canvas + JS, без залежностей)
  logic.js                 ігрова логіка: поле, фігури, очки, рівні (працює і в Node)
  game.js                  рендер, перетягування, ефекти, екрани, збереження
  tetris.js                логіка тетрісу: поле 10×20, SRS, гравітація, очки (працює і в Node)
  tetris-ui.js             екран тетрісу: рендер, жести, кнопки
app/src/main/java/...      MainActivity: повноекранний WebView, кнопка «Назад», вібрація
tests/                     тести логіки та бот для балансування рівнів
```

Нативна частина складається з одного `Activity` без сторонніх бібліотек. Уся гра живе в `assets/www`,
тому її можна відкрити й у звичайному браузері: `app/src/main/assets/www/index.html`.

### Тести й баланс

```bash
node tests/logic.test.js          # юніт-тести логіки
node tests/tetris.test.js         # юніт-тести тетрісу
node tests/simulate.js 100        # бот проходить кожен рівень 100 разів: % перемог і зірки
node tests/simulate.js 60 --tune  # перерахувати ліміти фігур і варіанти розкладок рівнів
```

Таблиці `moves` і `variants` наприкінці `logic.js` згенеровані командою `--tune`.

### Локальна збірка

Android Studio (Ladybug або новіша) → Open → ця папка → Run. Або з терміналу:

```bash
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

### Підпис

`keystore/ivyblock-dev.jks` — **тестовий** ключ (пароль `ivyblock`), закомічений навмисно, щоб збірки з CI
ставились поверх одна одної. Перед публікацією в Google Play заміни його приватним ключем і передавай
паролі через секрети GitHub.
